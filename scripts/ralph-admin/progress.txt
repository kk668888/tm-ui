## Codebase Patterns
- Keep the admin template isolated from the component-library build so new app code does not leak into the published `tm-ui` package.
- Admin app uses `@admin/*` for its own source files and keeps `@/*` reserved for the tm-ui library source alias.
- Use `pnpm admin:dev` and `pnpm admin:build` for the admin template; root `pnpm build` remains the component-library build.
- The admin app resolves `tm-ui` to the local library source entry so new backend-template pages exercise the real component wrappers during development.
