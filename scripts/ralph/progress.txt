## Codebase Patterns
- Component registration: use `withInstall()` from `@/utils/with-install.ts` to make components installable via `app.use()`
- Each component directory has: `component.ts` (withInstall wrapper), `Component.vue`, `index.ts` (re-exports from component)
- Library entry point (src/index.ts) imports all components and CSS, registers them via install()
- TailwindCSS v4 uses `@import "tailwindcss"` (not old @tailwind directives) + `@tailwindcss/vite` plugin
- Directory naming: lowercase with hyphens (tm-button, tm-input, etc.)
---
- Attribute forwarding: `useForwardAttrs()` composable from `@/utils` strips class/style
- v-model pattern: `const value = computed({ get: () => props.modelValue, set: (v) => emit('update:modelValue', v) })`
- Chinese defaults across all components
